# ООП на C++: наследование, сериализация Boost, Qt и связка с C#

Лабораторные по объектно-ориентированному программированию. Сквозная тема: иерархия классов с полиморфизмом, контейнер объектов через указатель на базовый класс и сохранение его в файл через Boost.Serialization. От работы к работе меняется интерфейс: консоль, затем Qt, затем C# поверх C++ библиотеки.

| Лаба | Что сделано |
|---|---|
| [lab2](lab2) | Консольное приложение: группа студентов, класс `RikhelgofStarosta` наследуется от `RikhelgofStudent`. Студенты хранятся в `vector<shared_ptr<...>>`, группу можно сохранить в файл и загрузить обратно |
| [lab3](lab3) | Картотека сотрудников на Qt Widgets. Два класса (`BaseItem` и `DerivedItem` с должностью и зарплатой), каждый сам рисует себя через `QPainter`. Отрисовка списка через `std::for_each` + `std::bind`. Меню: сохранить, загрузить, очистить |
| [lab4](lab4) | То же плюс редактирование: окно со списком и карточкой сотрудника, добавление, изменение и удаление. Поля формы строит сам объект (`setupEditForm` / `loadFromEditForm`), поэтому окну не нужно знать тип записи |
| [lab6](lab6) | Гараж болидов F1: логика и сериализация в C++ DLL (`native`), интерфейс на C# WinForms (`managed`), связь через `DllImport` |

## Стек

C++17, Boost.Serialization, Qt 6 Widgets, C# (.NET 8, WinForms), CMake, vcpkg.

## Сборка

Нужны Visual Studio 2022 с C++, [vcpkg](https://github.com/microsoft/vcpkg) и, для lab3 и lab4, Qt 6 для MSVC.

```
set VCPKG_ROOT=C:\vcpkg
set QT_DIR=C:\Qt\6.8.3\msvc2022_64
cmake --preset x64
cmake --build --preset release
```

Boost подтянется через vcpkg по `vcpkg.json`. Если Qt не установлен, соберутся только lab2 и dll для lab6. Папку можно открыть и в самой Visual Studio через «Открыть папку», она подхватит `CMakePresets.json`.

C# часть lab6 собирается после dll:

```
cd lab6/managed
dotnet run
```
